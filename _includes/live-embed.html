{%- comment -%} Embeds a resource served off the campus data server. Params: path required path on the data server, e.g. "/latest.gif" kind "image" (default) or "frame" title panel heading note small print under the panel height CSS height for frames (default 34rem via the stylesheet) refresh seconds between silent reloads of an image (0 / omitted = never) id optional element id The server address itself comes from site.data_host, so it is never written into a page. When the visitor is on https:// and the data server is still http:// the browser would block the embed outright, so site.js swaps in a click-through card instead of leaving a broken white box on the page. {%- endcomment -%} {%- assign kind = include.kind | default: 'image' -%} {%- assign url = site.data_host | append: include.path -%}
