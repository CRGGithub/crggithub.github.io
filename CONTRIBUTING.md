## Contributing

This is the public site for the NWU Lekwena radar and the NWU-WRF forecast, maintained by the
Climatology Research Group at North-West University. Corrections and improvements are welcome.
Please note that this project is released with a [Contributor Code of Conduct][code-of-conduct];
by participating you agree to abide by its terms.

## Making a change

1. [Fork][fork] and clone the repository, and create a branch:
   `git checkout -b my-change`.
2. Install the dependencies and run the site locally:

   ```bash
   bundle install
   bundle exec jekyll serve
   ```

   Then open <http://localhost:4000>.
3. If you touched the stylesheet, compile it once with Ruby Sass 3.7 before pushing. GitHub
   Pages builds with Ruby Sass 3.7, which rejects some things the local Jekyll 4 accepts, and a
   Sass error ships the site with no CSS at all. The exact commands are in the README under
   "Mind the version gap".
4. Push to your fork and [open a pull request][pr].

Some things to keep in mind:

- Product lists live in `_data/`, not in page markup. Adding a WRF field or a weather station
  is usually a single entry there.
- The data server's address is written in exactly one place, `data_host` in `_config.yml`.
  Never put the server's IP address in a page.
- `_data/radar_status.yml` is generated by a workflow. Do not edit it by hand; to force the
  radar's status, use `radar.status` in `_config.yml`.
- Keep each change focused, and write a commit message that says why, not just what.
